---

입력 파일(`data/filtered_combined_data.jsonl`)과 출력 파일(`data/summarized_data.jsonl`)을 직접 읽어서 진행 상황을 리포트하세요.

## 체크 항목

1. **전체 레코드 수**: 입력 파일의 줄 수 (비어있는 줄 제외)
2. **완료 수**: 출력 파일에서 `video_id` 개수
3. **남은 수**: 전체 - 완료
4. **진행률**: 완료 / 전체 × 100 (%)
5. **경고**: `summarize_with_exaone.py`에 `breakpoint()`가 존재하면 반드시 경고

## 출력 형식 예시

```
진행 상황
──────────────────
전체  : 150개
완료  : 42개
남은  : 108개
진행률: 28.0%

⚠️  경고: summarize_with_exaone.py에 breakpoint()가 남아있습니다. 프로덕션 실행 전 제거하세요.
```

파일이 없는 경우 명확히 표시하세요 (예: "출력 파일 없음 — 아직 실행 안 됨").
한국어로 출력하세요.
